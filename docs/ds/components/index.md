# Components overview

Seven building blocks, all tokenized, all a11y-tested, all typed.

| Component                                   | Purpose                                  |
| ------------------------------------------- | ---------------------------------------- |
| [Button](./button)                          | Primary and secondary actions            |
| [Badge](./badge)                            | Compact status indicator                 |
| [FreshnessTimestamp](./freshness-timestamp) | Realtime age with staleness thresholds   |
| [AlarmIndicator](./alarm-indicator)         | Attention-grabbing composed alert        |
| [Layout](./layout)                          | Responsive shell scaffold with landmarks |
| [MapView](./mapview)                        | Leaflet map wrapping                     |
| [DataTable](./datatable)                    | Virtualized generic table                |

For live examples, browse [Storybook](https://frontend-arch-poc-storybook.netlify.app).
